Principal Component Analysis (PCA) — From Scratch
Welcome to the Principal Component Analysis (PCA) Implementation repository! This project showcases a detailed and step-by-step implementation of PCA, one of the most essential dimensionality reduction techniques in machine learning and data science.

🚀 Project Overview
PCA is a statistical technique used to emphasize variation and bring out strong patterns in a dataset. It helps in reducing the number of dimensions without much loss of information. This project aims to:

Implement PCA from scratch using NumPy, without relying on pre-built libraries like Scikit-Learn.

Demonstrate PCA step-by-step on a real dataset.

Visualize the data before and after PCA transformation to understand its effectiveness.

🔍 Key Features
📊 Eigen Decomposition for identifying principal components

🔢 Covariance Matrix Calculation

📉 Variance Retention Analysis

📈 2D Visualization of Transformed Data

🧠 Focus on conceptual understanding, not just code
